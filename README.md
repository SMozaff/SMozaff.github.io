# IFEM Landing Page

Static GitHub Pages landing page designed for:
- Soheil Mozaffari
- Interface-First Execution Methodology (IFEM)
- Primary DOI: 10.5281/zenodo.20621561
- Runtime Manual DOI: 10.5281/zenodo.21330255
- ORCID: 0009-0001-2428-1295

## Deploy

Replace the current contents of the root of the `so-muzaff.github.io` repository with:

- `index.html`
- `assets/styles.css`
- `assets/script.js`

Commit to `main`. GitHub Pages should redeploy automatically.

## Notes

- The page is intentionally framework-free: HTML5 + CSS + vanilla JavaScript.
- Core content remains readable without JavaScript.
- Motion respects `prefers-reduced-motion`.
- Structured data connects Soheil Mozaffari, ORCID, and the primary IFEM publication.
- The rest of the multi-page website can be built later against the same visual and content rails.
