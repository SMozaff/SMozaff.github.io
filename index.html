01 / ABOUT

Position and scope

Make the boundary legible.

Soheil Mozaffari works on software architecture and execution methodologies with an emphasis on explicit interfaces, composability, coordination, and verifiability.

His principal authored methodology is IFEM — Interface-First Execution Methodology. IFEM treats interfaces and contracts as first-class engineering artifacts that can be established before implementation, helping independently executed work converge against defined boundaries.

03 / IFEM

Authored methodology

IFEM — Interface-First Execution Methodology.

IFEM is an interface-first software execution methodology authored by Soheil Mozaffari. Its central premise is that implementation should not be the first mechanism by which independently developed components discover how they must interact.

“Interfaces, ownership boundaries, contracts, and verification expectations should be explicit early enough to guide execution.”

The dedicated IFEM Doctrine site is the canonical property for its principles, execution model, diagrams, examples, and supporting material.
