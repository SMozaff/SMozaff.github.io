// 04 — روش‌شناسی

BOUND Method v3.0

BOUNDARY-ORIENTED UNIFIED DEVELOPMENT

BOUND یک روش مهندسی نرم‌افزار برای توسعهٔ موازی قابل اعتماد است. این روش مرزهای مسئولیت را صریح می‌کند، رفتار عبوری از مرزها را به قرارداد تبدیل می‌کند، اجرای مستقل را ممکن می‌سازد و انطباق را به‌صورت پیوسته راستی‌آزمایی می‌کند.

01

مرز

02

قرارداد

03

اجرای مستقل

04

راستی‌آزمایی پیوسته

«مرزها را مشخص کنید. قراردادها را تثبیت کنید. مستقل اجرا کنید. پیوسته اعتبارسنجی کنید.»

از IFEM تا BOUND: BOUND v3.0 ادامه و پالایش مفهومی IFEM است. IFEM: Interface → Contract → Execution → Verification. BOUND: Domain → Boundary → Contract → Execution → Verification. رابط‌ها از مرزهای مسئولیت شکل می‌گیرند؛ نه اینکه مرزها از روی رابط‌ها استنتاج شوند.
