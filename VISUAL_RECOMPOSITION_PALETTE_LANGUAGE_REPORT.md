# Visual Recomposition / Palette / Language Control Report

## Changes
- Rebalanced the near-black palette to a lighter deep-navy system while preserving cyan, violet, emerald, amber and rose signal accents.
- Reduced background orb/scanline intensity and softened terminal shadows to lower eye strain.
- Moved language switching into a persistent high-visibility floating pill below the fixed navigation.
- Removed the duplicate language item from the main nav/mobile menu; footer language controls remain as a secondary route.
- Persian typography no longer uses Vazirmatn as the primary face. It now prefers Tahoma / DejaVu Sans / Arial with the existing locally embedded Vazirmatn retained only as a reliable fallback.
- Re-composed Professional Focus into a 3+2 card rhythm on desktop instead of five narrow equal cards.
- Re-composed Interactive Engineering Lab into a desktop editorial/instrument split: explanatory context left, tabs and instrument surface right.
- Re-composed Selected Work into a two-column project atlas on desktop and one-column stack on smaller screens.
- Increased breathing room and visual hierarchy in BOUND Method, Publications and Records sections.

## Scope preserved
- No content claims changed.
- No DOI, schema, canonical, hreflang, project records or publication data changed.
- English/Persian direct static language routes remain `index.html` and `fa/index.html`.
