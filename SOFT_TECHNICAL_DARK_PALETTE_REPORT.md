# Soft Technical Dark Palette Pass

This pass changes only the visual palette/contrast treatment of the current Titr + Koodak build.

## Palette

- Page background: `#101827`
- Secondary surface: `#141F32`
- Cards / panels: `#1A2940`
- Raised panels: `#21324C`
- Borders: `#31445F`
- Main text: `#E8EDF3`
- Secondary text: `#A7B3C4`
- Cyan: `#4FB3C8`
- Violet: `#8D82CF`
- Emerald: `#5AAE8A`
- Amber: `#D4A24C`
- Rose: `#C77884`

## Comfort adjustments

- Raised panels away from near-black so sections have visible depth.
- Reduced scanline opacity.
- Reduced ambient orb opacity.
- Reduced cyan/violet/green/rose glow intensity.
- Softer white/secondary typography instead of stark white-on-black.
- Hero/boot/footer remain the darkest areas to preserve the Linux/terminal identity.
- Accent colors remain semantic signals rather than dominating the page.

## Preserved

- Titr headings and Koodak body text in Persian.
- EN/FA language switch behavior.
- Boot sequence and interactive systems.
- Current BOUND/IFEM content and six project records.
- Metadata, schema, canonical/hreflang and routes.
